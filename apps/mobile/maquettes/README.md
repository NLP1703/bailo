# Maquettes — écrans terrain M1

Source des 16 maquettes de la première version (lot LM1), dessinées sur la toile de design
« Maquettes Bailo mobile — écrans terrain M1 » dans Claude. Chaque fichier `.dc.html` est un
écran de téléphone (390 × 844) ; `canvas.json` donne leur disposition sur la toile.

Ces fichiers s'affichent sur la toile (ils ont besoin de son moteur d'affichage) ; ils sont
gardés ici pour l'historique et la revue de code. La liste de référence des écrans est dans
[`../docs/03-ecrans-et-navigation.md`](../docs/03-ecrans-et-navigation.md).
